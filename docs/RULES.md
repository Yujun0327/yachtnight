# Yacht Night — Rules

Both rulesets share the turn shape: up to **three rolls** of five dice, holding any subset
between rolls, then write the result into exactly one empty box (even if it scores zero).
The game ends when every box on every sheet is filled; highest total wins.

## Classic Yacht (12 boxes)

| Box | Requirement | Score |
| --- | --- | --- |
| Ones … Sixes | — | sum of the matching dice |
| Choice | — | sum of all five dice |
| Four of a Kind | ≥4 of one face | sum of the four matched dice |
| Full House | exactly 3 + 2 | sum of all five dice |
| Little Straight | 1-2-3-4-5 exactly | 30 |
| Big Straight | 2-3-4-5-6 exactly | 30 |
| Yacht | five of a kind | 50 |

No upper-section bonus, no repeat-Yacht bonus, no Joker.

## Yahtzee-style (13 boxes)

| Box | Requirement | Score |
| --- | --- | --- |
| Ones … Sixes | — | sum of the matching dice |
| Three of a Kind | ≥3 of one face | sum of ALL five dice |
| Four of a Kind | ≥4 of one face | sum of ALL five dice |
| Full House | 3 + 2 (five of a kind qualifies via Joker only) | 25 |
| Small Straight | any run of four | 30 |
| Large Straight | any run of five | 40 |
| Five of a Kind | five of a kind | 50 |
| Chance | — | sum of all five dice |

**Upper bonus**: 63+ across Ones–Sixes earns +35.

**Extra five-of-a-kinds**: if the Five of a Kind box already holds a 50, each further
five-of-a-kind earns a +100 bonus and the roll becomes a **Joker**:

1. The matching upper box must be taken if it is open.
2. Otherwise any open lower box may be taken at its fixed value (Full House 25,
   Small Straight 30, Large Straight 40; 3K/4K/Chance score the dice sum).
3. Otherwise an open upper box must be zeroed.

If the Five of a Kind box holds a 0, later five-of-a-kinds earn **no** bonus but the
Joker placement rules still apply.
